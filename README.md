# Мобильное Android приложение на **Flutter** со встроенной офлайн нейросетью для определения чизкейков.

Спасибо, амиго, за глупую идею; спасибо, Пиф, за анимации.

## Стек 
* **Framework:** Flutter / Dart
* **Пакеты:** `camera`, `tflite_flutter`, `image`
* **ML:** TensorFlow Lite (`MobileNetV2`)

## Установка на Android
1. Скачайте файл `app-release.apk`.
2. Установите APK на смартфон (при необходимости разрешите установку из неизвестных источников).
3. Разрешите приложению доступ к камере при первом запуске.

## Сборка из исходников
```bash
git clone https://github.com/Jase-de-Luce/Cheesecake-Identifier-App
cd Cheesecake-Identifier-App
flutter pub get
flutter build apk --release
```

# Mobile Android application built with **Flutter** featuring an embedded offline neural network for cheesecake detection.

Thanks, amigo, for the silly idea; thanks, Pif, for the animations.

## Tech Stack
* **Framework:** Flutter / Dart
* **Packages:** `camera`, `tflite_flutter`, `image`
* **ML:** TensorFlow Lite (`MobileNetV2`)

## Android Installation
1. Download the `app-release.apk` file.
2. Install the APK on your smartphone (allow installation from unknown sources if prompted).
3. Grant camera permission to the app on first launch.

## Build from Source
```bash
git clone https://github.com/Jase-de-Luce/Cheesecake-Identifier-App
cd Cheesecake-Identifier-App
flutter pub get
flutter build apk --release
```
